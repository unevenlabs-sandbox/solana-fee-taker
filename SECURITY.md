# Security Policy

Please report vulnerabilities in the Relay Fee Taker program
(`3mB3kHbyvn45hZ87Lp93wY5oKBrAeqKCgRE1mHj9PYYg`) privately to
support@relay.link. Do not open a public issue.

Include the program id, a description of the issue, and steps or a transaction
that reproduces it. We will acknowledge reports promptly and keep you informed
as we work on a fix.

The program is stateless and holds no funds between transactions; a report
about funds left resting in the fee taker PDA or its token accounts is still
welcome, as that indicates a misuse by an integrator.
